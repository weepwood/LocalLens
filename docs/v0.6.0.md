# LocalLens v0.6.0

`v0.6.0` 将 Windows 客户端和 Go 服务端整合为一个统一应用体验。用户只需要启动 `LocalLens.exe`，客户端会创建本地配置、启动内置服务端、完成健康检查并自动连接 `127.0.0.1`。

## 统一 Windows 安装包

Windows 客户端包新增：

```text
LocalLens-Client-Windows-x64/
├── LocalLens.exe
├── flutter_windows.dll
├── data/
├── plugins/
└── runtime/
    ├── LocalLensServer.exe
    └── media-tools/
        └── README.txt
```

`runtime/LocalLensServer.exe` 使用 Windows GUI 子系统构建，启动时不会弹出命令行窗口。

用户配置和运行数据不写入安装目录，而是保存到：

```text
%LOCALAPPDATA%\LocalLens\
├── config\server.json
├── config\server.json.backup
├── data\
├── cache\
├── logs\server.log
└── runtime\server.pid
```

## 首次启动

Windows 第一次启动默认进入本机一体化向导：

1. 设置服务器名称；
2. 设置媒体库名称；
3. 通过系统目录选择器选择图片和视频目录；
4. 设置端口；
5. 选择是否允许手机和局域网设备访问；
6. 自动生成高强度管理员 Token；
7. 创建配置并启动内置服务端；
8. 健康检查成功后自动进入媒体库。

仍然可以选择“连接另一台 LocalLens 服务器”，现有远程客户端模式保持兼容。

## Server Supervisor

Flutter 客户端新增内置服务端监督器，负责：

- 查找安装包中的服务端运行时；
- 创建 `%LOCALAPPDATA%` 数据目录；
- 生成管理员 Token；
- 原子保存配置并保留备份；
- 启动、停止和重启服务端；
- 保存服务端 PID；
- 检测端口占用；
- 轮询 `/api/v1/server` 健康状态；
- 捕获标准输出和错误日志；
- 服务异常退出后按 2 秒、5 秒、15 秒退避重启；
- 连续失败超过三次后停止自动重启并显示错误。

## 可视化服务器设置

Windows 左侧导航中的“连接设置”在本机模式下变为“本机服务器设置”。

设置页面支持：

- 查看运行状态、端口、PID 和服务端版本；
- 启动、停止和重启内置服务端；
- 打开数据目录和日志目录；
- 修改服务器名称；
- 修改端口；
- 开启或关闭局域网访问；
- 修改主媒体库名称和目录；
- 开启或关闭启动扫描与文件监听；
- 调节缩略图、元数据和转码 Worker；
- 选择软件编码、NVENC、QSV 或 AMF；
- 设置转码缓存容量；
- 保存配置后自动重启服务器。

配置使用临时文件写入，并在覆盖正式配置前生成 `server.json.backup`。

## FFmpeg

为控制安装包体积和第三方二进制分发，Windows 客户端包当前不直接附带 FFmpeg。

需要视频缩略图、广泛元数据兼容或 HLS 转码时，将以下文件放入：

```text
runtime\media-tools\ffmpeg.exe
runtime\media-tools\ffprobe.exe
```

首次创建本地配置时会自动检测这些文件。JPEG、PNG 和 GIF 的原生图片缩略图不依赖 FFmpeg。

## 退出行为

当前版本中，退出 `LocalLens.exe` 会停止由它托管的本机服务端。系统托盘后台运行、Windows 登录后自动启动和可选 Windows Service 将在后续版本增加。

## 兼容性

- 现有 SQLite 数据库保持兼容；
- 现有独立服务端配置保持兼容；
- Android 客户端继续通过局域网连接 Windows 服务；
- Windows 仍可选择远程服务器模式；
- 不需要删除数据库或重新扫描已有媒体库。
