# LocalLens v0.4.0

`v0.4.0` 将原先独立、简单的图片页和视频页重构为统一沉浸式媒体查看器，重点完善 Windows 与 Android 的全屏查看、连续浏览和视频控制体验。

## 统一媒体查看会话

从时间线、物理目录、相册或标签打开媒体时，客户端会携带当前已经加载的结果集与当前索引。

因此查看器可以：

- 连续浏览上一项和下一项
- 在图片和视频之间切换
- 在查看器中更新收藏和评分并同步回媒体网格
- 预加载相邻缩略图和图片
- 显示当前位置，例如 `18 / 126`

## 图片查看器

- Windows 与 Android 沉浸式黑色查看界面
- 缩略图立即显示，原图完成后渐进替换
- 鼠标滚轮缩放
- 双击在适应窗口和 2.5 倍之间切换
- 双指缩放和平移
- 放大状态下拖动图片，适应窗口时左右滑动切换媒体
- 左右旋转
- 一键恢复适应窗口
- 上一项、下一项按钮
- 底部胶片栏
- 相邻图片预加载
- 原图加载失败时继续保留缩略图

### Windows 图片快捷键

| 快捷键 | 功能 |

| `←` / `→` | 上一项 / 下一项 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 恢复适应窗口 |
| `R` | 顺时针旋转 |
| `F` | 收藏或取消收藏 |
| `I` | 显示媒体信息 |

| `Esc` | 退出全屏或关闭查看器 |

## 视频播放器

继续使用 `media_kit` 作为播放内核，但移除了默认控制层，改为 LocalLens 自定义控制界面。

新增：

- 播放、暂停
- 前进和后退 10 秒
- 自定义进度条与缓冲进度
- 音量和静音
- 0.5×～2.0× 播放速度
- 全屏切换
- 3 秒无操作自动隐藏控制栏
- 播放时保持屏幕常亮
- 初始化、缓冲和错误状态
- Android 双击左侧或右侧快退、快进
- 视频完成后更可靠的完成判定

### 显式续播

当服务端存在有效播放进度时，不再直接强制跳转，而是显示：

- 从头播放
- 继续播放

用户未选择时，5 秒后自动继续。

不满足以下条件时不会弹出提示：

- 进度不足 10 秒
- 已经播放完成
- 距离结尾不足 30 秒

### 播放进度保存

播放进度会在以下时机保存：

- 每 10 秒
- 暂停时
- 拖动进度结束时
- 应用进入后台时
- 切换媒体时
- 关闭查看器时
- 播放完成时

完成判定使用 `10 秒` 与视频总时长 `2%` 中较大的值，并限制最高为 60 秒。

## 媒体信息面板

桌面端从右侧显示媒体信息，窄屏设备使用同一自适应面板。

包含：

- 文件名
- 相对目录
- 分辨率
- 文件大小
- MIME 类型
- 视频编码
- 拍摄时间及来源
- 相机型号
- GPS 坐标
- 收藏状态
- 0～5 星评分

## 全屏行为

### Windows

- 使用 `window_manager` 进入真正的窗口全屏
- `F11` 切换全屏
- `Esc` 优先退出全屏，再关闭查看器
- 退出后恢复原来的窗口状态

### Android

- 进入查看器后启用沉浸式系统 UI
- 退出查看器时恢复系统状态栏和导航栏
- 视频播放期间启用屏幕常亮

## 升级

Windows 客户端直接替换旧客户端目录即可。服务器地址和设备令牌保存在系统首选项中，不会因为替换程序目录而丢失。

服务端数据库和 `config.json` 与 v0.3.0 保持兼容，不需要重新扫描或删除数据库。

建议客户端与服务端一起升级，以保持版本显示和正式安装包一致。

## 本版本未包含

以下能力需要服务端新增独立的媒体处理管线，未放入本次客户端查看器重构：

- 视频进度条预览雪碧图
- 外部字幕自动扫描
- 多音轨与字幕选择菜单
- HLS 兼容转码
- 1080p、720p、480p 质量切换

这些功能适合在后续版本中基于持久化转码任务队列继续实现。
