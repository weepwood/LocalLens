# LocalLens v0.3.0

`v0.3.0` 是 LocalLens 的第一轮完整视觉升级，同时包含此前 `v0.2.2` 的大媒体库缩略图可靠性修复。

## 客户端视觉升级

- 建立统一的浅色和深色 Design Tokens
- 使用 Material 3 作为基础视觉系统
- 使用 shadcn_ui 构建统一卡片和表面层级
- 使用 Lucide Icons 替换风格不一致的默认图标
- 使用 Skeletonizer 提供媒体网格和目录页骨架屏
- Windows 窗口默认居中，并设置合理的默认与最小尺寸

## 主框架

Windows 客户端改为新的桌面侧边栏：

- LocalLens 品牌标识
- 块状导航选中状态
- 宽屏和紧凑两种侧边栏
- 顶部服务器连接状态
- 常驻连接设置入口

移动端继续使用底部导航，但统一了顶部栏、图标和选中状态。

## 时间线与媒体网格

- 新的页面标题和筛选工具栏
- 按媒体库、图片、视频、收藏和评分筛选
- 舒适网格与紧凑网格切换
- 拍摄日期分组与项目数量提示
- 悬停时显示文件名、日期和文件大小
- 收藏、媒体管理、视频时长和评分作为轻量叠加信息
- 统一加载、空状态、错误状态和加载更多状态

## 物理目录

- Windows 桌面端使用目录树与媒体区双栏布局
- 目录行拥有清晰的层级、展开与选中状态
- 提供面包屑导航
- 目录结构仍与服务端 Windows 媒体根目录一致
- 客户端只接收相对路径，不暴露盘符和绝对路径

## 连接页面

- 重做首次连接和修改服务器地址页面
- 修改 IP 时自动保留原 Token
- 移动端继续支持二维码配对
- 错误信息使用独立状态面板展示

## 升级

Windows 客户端直接使用新版压缩包替换旧客户端目录即可。连接地址和 Token 保存在系统首选项中，不会因为替换程序文件而丢失。

服务端配置与数据库格式保持兼容。建议同时升级服务端，以获得 `v0.2.2` 的原生 JPEG、PNG、GIF 缩略图、失败任务恢复、优先队列和诊断接口。
