# LocalLens v0.6.1

`v0.6.1` 将 Windows 版本调整为真正的一体化应用，并补齐 FFmpeg、自定义数据目录、安全重置、多媒体库和 Windows 桌面体验修复。

## Windows 一体化下载包

普通 Windows 用户只需要下载并完整解压：

```text
LocalLens-Windows-x64.zip
```

最终 Windows ZIP 包含：

```text
LocalLens.exe
BUNDLE-MANIFEST.json
runtime/
├── LocalLensServer.exe
└── media-tools/
    ├── ffmpeg.exe
    ├── ffprobe.exe
    └── FFMPEG-NOTICE.txt
```

独立服务端 `LocalLens-Server-Windows-x64.zip` 继续保留，但只用于高级部署。

## 内置 FFmpeg

Windows 一体化包固定包含 FFmpeg `8.1.2` Essentials Build。CI 会：

1. 从固定版本地址下载归档；
2. 校验下载归档 SHA-256；
3. 运行 `ffmpeg -version` 和 `ffprobe -version`；
4. 将二进制复制到最终 ZIP；
5. 将版本、路径和文件 SHA-256 写入 `BUNDLE-MANIFEST.json`；
6. 解压最终 ZIP 后再次验证二进制完整性；
7. 使用 ZIP 内的媒体工具配置启动内置服务端并执行健康检查。

因此视频缩略图、FFprobe 元数据和 HLS 转码不再依赖用户手工安装 FFmpeg。

## Windows 终端窗口闪烁

媒体扫描期间，服务端会频繁调用 FFprobe 读取视频元数据，并调用 FFmpeg 生成缩略图。旧版将这些工具作为普通控制台程序启动，导致黑色终端窗口反复弹出并立即消失。

新版在 Windows 上通过 `CREATE_NO_WINDOW` 和隐藏窗口参数启动后台媒体处理子进程。更换媒体库后仍会正常重新扫描，但不会再为每个媒体文件弹出终端窗口。

保存本机服务器配置时，服务仍会执行一次正常的停止和重启状态切换；这与旧版持续闪烁多个 FFmpeg/FFprobe 窗口不同。

## 多媒体库

首次设置向导和“本机服务器设置”都支持多个媒体库。每个媒体库可以：

- 选择独立的图片或视频文件夹；
- 设置显示名称；
- 开启或关闭子文件夹扫描；
- 单独启用或停用；
- 更换目录；
- 从配置中移除。

应用会阻止重复目录，并要求至少保留一个媒体库。保存后本机服务会重启并同步全部媒体库配置，不再只覆盖 `libraries.first`。

## Windows 中文字体

Windows 客户端现在优先使用系统自带的 `Microsoft YaHei UI`，并提供以下字体回退：

- Microsoft YaHei；
- Segoe UI；
- Noto Sans CJK SC / Noto Sans SC；
- PingFang SC；
- Arial Unicode MS。

标题取消了对中文显示不友好的负字距，并统一正文、标签和标题的行高。此方案使用系统字体，不会把字体文件打进安装包。

## 用户指定数据目录

首次启动向导会分别选择：

- **媒体目录**：用户的原始图片和视频；
- **LocalLens 数据目录**：配置、SQLite 数据库、缩略图、转码缓存和日志。

选择上级目录后，应用会创建独立的：

```text
LocalLensData/
```

媒体目录和数据目录不能相同，也不能互相包含。默认数据目录仍为：

```text
%LOCALAPPDATA%\LocalLens
```

使用自定义目录时，固定位置只保存目录指针：

```text
%LOCALAPPDATA%\LocalLens.storage.json
```

## 数据目录迁移

更换数据目录时，应用会：

1. 停止内置服务端；
2. 验证目标目录；
3. 迁移配置、数据库、缓存和日志；
4. 更新配置及数据目录指针；
5. 从新目录启动服务端；
6. 启动成功后清理旧的 LocalLens 数据目录。

迁移不会移动或修改原始媒体文件。

## 清除数据并恢复默认

“清除 LocalLens 数据并恢复默认”会删除：

- 本机服务端配置和管理员 Token；
- SQLite 媒体索引；
- 缩略图和转码缓存；
- 日志和运行状态；
- 自定义数据目录指针。

完成后返回首次设置向导。媒体目录中的原始图片和视频不会被删除。非默认目录只有存在 `.locallens-data-root.json` 标记时才允许递归清理。

## 手动删除本地数据后的恢复

客户端仍保存本机模式，但 `server.json` 或整个 LocalLens 数据目录被手动删除时，新版会自动清除失效的连接状态并返回首次设置向导。

如果配置文件存在但已经损坏，启动错误页提供“清除本机配置并重新设置”。外接磁盘只是暂时断开时，应用会保留数据目录指针，重新连接磁盘并重启后仍可重新发现原配置。

## 构建清单与冒烟测试

`BUNDLE-MANIFEST.json` 包含：

- 客户端和服务端版本；
- Git 提交 SHA 与 Actions 构建编号；
- 客户端、服务端和媒体工具相对路径；
- FFmpeg 版本；
- FFmpeg 与 FFprobe SHA-256；
- UTC 构建时间。

GitHub Actions 会执行：

- Go 单元测试和 Windows 服务端构建；
- Flutter 测试与静态分析；
- Windows 和 Android 构建；
- FFmpeg、FFprobe 下载和完整性校验；
- Windows 一体化 ZIP 完整性检查；
- 内置服务端真实启动；
- `/api/v1/health` 健康检查；
- 构建产物上传。

## 升级建议

1. 下载 `LocalLens-Windows-x64.zip`；
2. 解压到新目录，不要只复制 `LocalLens.exe`；
3. 确认 `runtime` 目录完整存在；
4. 启动 `LocalLens.exe`；
5. 在首次设置或本机服务器设置中添加所需的全部媒体库；
6. 需要时迁移 LocalLens 数据目录。
