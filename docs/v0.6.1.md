# LocalLens v0.6.1

`v0.6.1` 将 Windows 版本调整为真正的一体化应用，并补齐 FFmpeg、自定义数据目录和安全重置能力。

## Windows 一体化下载包

普通 Windows 用户只需要下载：

```text
LocalLens-Windows-x64.zip
```

独立服务端 `LocalLens-Server-Windows-x64.zip` 继续保留，但只用于高级部署。

最终 Windows ZIP 根目录包含：

```text
LocalLens.exe
BUNDLE-MANIFEST.json
runtime/
├── LocalLensServer.exe
└── media-tools/
    ├── ffmpeg.exe
    ├── ffprobe.exe
    └── FFMPEG-NOTICE.txt
```

缺少任何必要文件都会直接导致构建失败。

## 内置 FFmpeg

Windows 一体化包固定包含 FFmpeg `8.1.2` Essentials Build：

- `runtime\media-tools\ffmpeg.exe`；
- `runtime\media-tools\ffprobe.exe`；
- `runtime\media-tools\FFMPEG-NOTICE.txt`。

CI 会执行：

1. 从固定版本 URL 下载归档；
2. 验证 `ffmpeg -version` 和 `ffprobe -version`；
3. 将二进制复制到最终 ZIP；
4. 记录版本、相对路径和 SHA-256；
5. 解压最终 ZIP 后再次运行 FFmpeg 和 FFprobe；
6. 使用 ZIP 内的媒体工具启动内置服务端并执行健康检查。

因此视频缩略图、FFprobe 元数据和 HLS 转码不再依赖用户手工安装 FFmpeg。

## 用户指定数据目录

首次启动向导现在分别要求选择：

- **媒体目录**：用户的原始图片和视频；
- **LocalLens 数据目录**：配置、SQLite 数据库、缩略图、转码缓存和日志。

选择一个上级目录后，应用会创建独立的：

```text
LocalLensData/
```

媒体目录和数据目录不能相同，也不能互相包含，避免扫描自身缓存或重置时影响原始媒体。

默认数据目录仍为：

```text
%LOCALAPPDATA%\LocalLens
```

使用自定义目录时，固定位置仅保留目录指针：

```text
%LOCALAPPDATA%\LocalLens.storage.json
```

## 数据目录迁移

“本机服务器设置”新增数据存储区域。更换目录时，应用会：

1. 停止内置服务端；
2. 验证目标目录为空或已标记为 LocalLens 专用目录；
3. 迁移配置、数据库、缓存和日志；
4. 更新配置及数据目录指针；
5. 从新目录启动服务端；
6. 启动成功后删除旧的 LocalLens 数据目录。

迁移不会移动或修改原始媒体文件。

## 清除数据并恢复默认

设置页新增二次确认的“清除 LocalLens 数据并恢复默认”。该操作会删除：

- 本机服务端配置和管理员 Token；
- SQLite 媒体索引；
- 缩略图和转码缓存；
- 日志和运行状态；
- 自定义数据目录指针。

重置完成后直接返回首次设置向导。媒体目录中的原始图片和视频不会被删除。

非默认目录只有存在 `.locallens-data-root.json` 标记时才允许被删除，以避免误删普通用户文件夹。

## 发布资产冒烟测试

CI 不只检查构建目录，而会：

1. 解压最终 ZIP；
2. 校验客户端、内置服务端、FFmpeg、FFprobe 和构建清单；
3. 运行 ZIP 内的 FFmpeg 和 FFprobe；
4. 创建临时媒体目录和数据目录；
5. 从解压目录启动 `runtime\LocalLensServer.exe`；
6. 轮询 `/api/v1/health`；
7. 健康检查通过后才上传 Windows Artifact。

## 构建清单

`BUNDLE-MANIFEST.json` 包含：

- 包名；
- 客户端和服务端版本；
- Git 提交 SHA 与 Actions 构建编号；
- 客户端和服务端相对路径；
- FFmpeg 版本；
- FFmpeg 与 FFprobe 相对路径及 SHA-256；
- UTC 构建时间。

## 旧版配置迁移

旧版客户端没有保存连接模式，只保存服务器地址和 Token。新版检测到旧配置后会显示选择页面：

- **使用本机内置服务器**：进入本机媒体目录和数据目录设置；
- **继续连接原来的服务器**：保留旧地址和 Token，并明确写入远程模式。

旧版位于 `%LOCALAPPDATA%\LocalLens` 的本机数据仍可直接使用，并可稍后迁移到其他磁盘。

## 升级建议

1. 下载 `LocalLens-Windows-x64.zip`；
2. 解压到新目录，不要只复制 `LocalLens.exe`；
3. 确认服务端和 FFmpeg 文件均存在；
4. 启动 `LocalLens.exe`；
5. 根据提示选择本机模式或原远程服务器模式；
6. 需要时在本机服务器设置中迁移数据目录。
