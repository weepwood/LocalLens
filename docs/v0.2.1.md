# LocalLens v0.2.1

`v0.2.1` 是针对 Windows 服务端 SQLite 写锁竞争和 Windows 客户端连接配置的稳定性热修复。

## 修复内容

### SQLite 后台任务锁竞争

修复以下警告反复出现的问题：

```json
{"level":"WARN","msg":"claim metadata job","error":"database is locked (5) (SQLITE_BUSY)"}
```

原因是全量扫描、文件监听、缩略图 Worker、元数据 Worker 和客户端写操作可能同时竞争 SQLite 的单写者锁。

本版本改进：

- SQLite `busy_timeout` 从 5 秒提高到 15 秒；
- 元数据和缩略图任务领取改为单条 `UPDATE ... RETURNING` 原子语句；
- 移除任务领取过程中“先查询、再更新”的竞争窗口；
- 对短暂 `SQLITE_BUSY` 增加指数退避重试；
- 全量扫描期间暂停后台 Worker 领取新任务；
- 启动自动扫描会先标记为运行状态，再启动后台 Worker；
- 锁竞争降级为调试日志，不再反复打印误导性的 WARN；
- 增加四个并发 Worker 领取任务且不重复的测试。

任务不会丢失。服务重启时，状态为 `running` 的任务仍会自动恢复为 `pending`。

### Windows 客户端修改服务器地址

- 左侧导航常驻“连接设置”；
- 旧服务器完全不可访问时仍可进入编辑页面；
- 自动带入旧地址和旧 Token；
- 新地址验证成功后才覆盖本地配置；
- 支持取消修改并返回客户端；
- Token 支持显示和隐藏。

## 升级方法

1. 关闭旧版 `LocalLensServer.exe`；
2. 备份服务端 `data` 目录；
3. 下载并解压 `LocalLens-Server-Windows-x64.zip`；
4. 保留原来的 `config.json` 和 `data` 目录；
5. 使用新版 `LocalLensServer.exe -config .\config.json` 启动；
6. Windows 客户端也建议更新，以获得“连接设置”入口。

本版本不增加数据库迁移，现有 v0.2.0 数据库可直接使用。

## 临时处理

尚未更新服务端时，可以把配置中的 Worker 数量临时降低：

```json
{
  "thumbnail_workers": 1,
  "metadata_workers": 1
}
```

这只能降低出现频率，不能彻底消除全量扫描持有写锁期间的竞争。正式解决方案是升级到 v0.2.1。
